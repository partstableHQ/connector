## beta.25 fixes (third CEO feedback round, same day)

1. **Export showed "(no record in compendium rev)" for parts the app was
   displaying.** Root cause: /paste/export re-fetched every part from the
   production edge; the edge throttled the sequential burst (first row
   survived, the rest fell back to the empty local compendium). Fix: a
   15-minute TTL cache (bounded, 4096 entries) now sits in front of every
   production call — typeahead, paste-grid enrichment, TDS panel, and
   exports all share it, so the export reuses exactly what the grid
   fetched. Verified live: warm cache → export carries 6/6 real
   descriptions, zero no-record rows; selected-rows filtering intact;
   bonus: exports are now instant and the edge sees far fewer calls.
2. **"Why you mention IQR mirror?"** — the export carried source labels
   (iqr_mirror/cenz/flis_graph), grades, confidence, holders, source
   lines. Export format stripped to the CEO ruling: Your part / Qty /
   Description / Substitutes (bare PNs). Single-part Substitutes sheet:
   PN / primary-or-substitute / description. Production's internal
   relationship vocabulary ("same_fsc") is mapped to substitute (or
   primary). "(no record in compendium rev)" reworded "(no record)".

NOTE: the TDS PANEL in the app still shows grade/confidence/sources —
that is the production /parts page design (partstable.com shows the same)
and was not part of the complaint; only the Excel file was stripped.
