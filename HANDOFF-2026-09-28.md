   Lookup view has an Export to Excel button.

   builder: rows + third panel on the right with the TDS."** → PasteView
   rebuilt as the master-detail quote-builder layout: AG Grid rows on

   full TDS sheet for the selected row in the right panel.
4. **Excel export matched the grid.** pasteRows enrichment now includes
   TDS substitutes (productionResultWithSubs), so the export carries the
   same verified substitutes the UI shows. Verified by unzipping the
   workbook: real description/category/xrefs for 875488-B21.
