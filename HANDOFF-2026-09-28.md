# HANDOFF — PartsTable Connector — 2026-09-28 (beta.25)

**Status: beta.25 deployed (installed app + portable + installer) and verified against live production data. Release hold UNCHANGED.**

## beta.25 fixes (third CEO feedback round, same day)

1. **Export showed "(no record in compendium rev)" for parts the app was
   displaying.** Root cause: /paste/export re-fetched every part from the
   production edge; the edge throttled the sequential burst (first row
   survived, the rest fell back to the empty local compendium). Fix: a
   15-minute TTL cache (bounded, 4096 entries) now sits in front of every
   production call — typeahead, paste-grid enrichment, TDS panel, and
   exports all share it, so the export reuses exactly what the grid
   fetched. Verified live: warm cache → export carries 6/6 real
   descriptions, zero no-record rows; selected-rows filtering intact;
   bonus: exports are now instant and the edge sees far fewer calls.
2. **"Why you mention IQR mirror?"** — the export carried source labels
   (iqr_mirror/cenz/flis_graph), grades, confidence, holders, source
   lines. Export format stripped to the CEO ruling: Your part / Qty /
   Description / Substitutes (bare PNs). Single-part Substitutes sheet:
   PN / primary-or-substitute / description. Production's internal
   relationship vocabulary ("same_fsc") is mapped to substitute (or
   primary). "(no record in compendium rev)" reworded "(no record)".

NOTE: the TDS PANEL in the app still shows grade/confidence/sources —
that is the production /parts page design (partstable.com shows the same)
and was not part of the complaint; only the Excel file was stripped.

## beta.24 additions (second CEO feedback round, same day)

1. **Checkbox selection** — per-row checkboxes + tri-state header
   checkbox (select all / deselect all / select some). The export button
   shows the tick count ("Export to Excel (2)") and exports exactly the
   ticked rows; nothing ticked → whole list. Backend: `POST /paste/export`
   accepts JSON `{paste, selected}`; raw-text path unchanged (tests cover
   both).
2. **Export button fixed** — the detached-anchor + immediate-revoke
   download pattern is unreliable in WebView2; downloads now anchor into
   the document with a deferred revoke, "Exporting…" state, inline error
   on failure. Same fix on the Lookup view export.
3. **Keyboard navigation** — ArrowUp/ArrowDown move the active row
   (selection follows, auto-scroll) and open its TDS sheet in the right
   panel; Enter re-opens. Verified in-browser: dispatched ArrowDown moved
   selection to 875488-B21 and the TDS panel rendered its sheet.
4. **Row click** — clicking anywhere on a row opens the TDS sheet AND
   ticks the row into the export selection (multi-select).

Verification: selected export carried only the 2 ticked PNs (zip-inspected);
full export carried all 4; export click went "Exporting…" → done, no error;
button label tracked selection (2 → 1 after keyboard move).

## CEO feedback this round → what changed

1. **"Why the fuck are you showing pricing?"** → All pricing removed
   (list price / last cost rows dropped from the data sheet; the export
   never had pricing). The numbers WERE live production data, not
   invented; data confidence (30% on 02CL197) is likewise the production
   value — the confidence score reflects how thinly sourced that part's
   production record is (dataOrg=dabergy, descriptionQuality=0), not an
   app-side failure.
2. **"Give the user copy/paste on part numbers and an Excel export even
   for a one-part lookup."** → Copy chips next to every part number in
   the data sheet; `GET /lookup/export` renders one part + its verified
   substitutes (grade / confidence / sources) as a two-sheet .xlsx; the
   Lookup view has an Export to Excel button.
3. **"Multiple part search is an abomination — reproduce the quote
   builder: rows + third panel on the right with the TDS."** → PasteView
   rebuilt as the master-detail quote-builder layout: AG Grid rows on
   the left (identity only: pn/qty/description/condition/category),
   full TDS sheet for the selected row in the right panel.
4. **Excel export matched the grid.** pasteRows enrichment now includes
   TDS substitutes (productionResultWithSubs), so the export carries the
   same verified substitutes the UI shows. Verified by unzipping the
   workbook: real description/category/xrefs for 875488-B21.
