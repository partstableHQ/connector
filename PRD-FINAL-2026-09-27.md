### 1.3 AG Grid v33 Theming (CRITICAL — gotcha from beta.12)

AG Grid v33 uses the **Theming API** (not CSS imports). The old CSS import
`ag-grid-community/styles/ag-theme-quartz.css` loads but the grid ignores it.

```tsx
import { ModuleRegistry, AllCommunityModule, themeQuartz } from 'ag-grid-community';
ModuleRegistry.registerModules([AllCommunityModule]);

const gridTheme = themeQuartz.withParams({
  rowHeight: 32,
  headerHeight: 36,
  fontSize: 12.5,
  fontFamily: "'IBM Plex Sans', sans-serif",
  backgroundColor: '#FFFFFF',
  foregroundColor: '#0F1923',
  borderColor: '#E5E7EB',
  oddRowBackgroundColor: '#F8F9FA',
  headerBackgroundColor: '#F8F9FA',
  headerTextColor: '#64748B',
  accentColor: '#0055DD',
  // NOTE: 'accentColour' (British spelling) does NOT exist — use 'accentColor'
});
```

For dark mode, create a second theme and swap:
```tsx
const gridThemeDark = themeQuartz.withParams({
  // same params but dark values
  backgroundColor: '#0F172A',
  foregroundColor: '#E2E8F0',
  borderColor: '#334155',
  oddRowBackgroundColor: '#1E293B',
  headerBackgroundColor: '#0F172A',
  headerTextColor: '#94A3B8',
});
```

Column defs must be typed: `ColDef<GridRow>[]` — untyped objects fail with
`NestedFieldPaths` error.

### 2.4 Full lookup flow

### 3.2 Parser

Uses `smartParse.ts` (production V5 parser, ported verbatim, 588 lines).
Located at `frontend/src/lib/smartParse.ts`.

Handles: lines, commas, semicolons, tabs, CSV, quantities (x4/4x/qty 4/qty:4/qty=4/qty4),
condition aliases (NEW/NOB/REF/USED/F/S), Excel spill (TSV), email prose, dates.
Returns: `{lines: ParsedLine[], mode: ParseMode, headerDetected: boolean}`.

ParsedLine: `{pn, qty, desc?, condition, conditionAssumed, rawLine}`.

Canonical conditions: NEW, NOB, REF, USED, F/S.
Unknown/missing → REF with conditionAssumed: true. Qty default: 1.

## 8. KNOWN GOTCHAS (from this session's debugging)

| Gotcha | Impact | Fix |
|---|---|---|
| AG Grid v33 Theming API | CSS imports don't work | Use `themeQuartz.withParams()` |
| AG Grid colDefs must be typed | Cryptic build error | `ColDef<T>[]` |
| React className vs CSS #id | Popover positioned off-screen | Match the selector |
| `.open` class pattern | React conditionally renders — no class toggle needed | Just render/unmount |
| React controlled inputs | Setting .value directly doesn't trigger React state | Use Object.getOwnPropertyDescriptor setter + dispatchEvent |
| localStorage + Wails | Persisted per-webview, works fine | No issue |
| typeahead race conditions | Stale responses overwrite fresh | AbortController + sequence guard |
| Production API User-Agent | Cloudflare rejects Go default UA | Set browser-style UA |
| /oauth/* Caddy route gets wiped | 404 on sign-in | Re-insert block, commit to fleet Caddyfile |
