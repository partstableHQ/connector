## Frontend stack (as of the React rewrite)

- **React 19** + TypeScript + Vite
- **AG Grid Community v33** (Themng API, NOT legacy CSS — use `themeQuartz.withParams(...)`)
- **No Tailwind** — hand-rolled CSS with production custom properties
- Fonts: IBM Plex Sans + JetBrains Mono (fontsource, bundled locally)
- Three views: LookupView, PasteView, SettingsView
- Tab navigation, dark mode toggle in topbar

### CRITICAL frontend gotchas (do not re-discover these)
1. **AG Grid v33**: `theme="legacy"` + CSS imports DO NOT work. Use `themeQuartz.withParams({...})` from the Theming API. The CSS import path `ag-grid-community/styles/ag-theme-quartz.css` loads but the grid ignores it.
2. **AG Grid v33 colDefs**: must be typed as `ColDef<T>[]` — untyped objects fail with a cryptic "NestedFieldPaths" error.
3. **PasteView**: the form POST works but driveBrowser in tests may fail against Cloudflare challenges. The E2E test (in-process) is the reliable verification.
4. **Typeahead**: 150ms debounce (local DB = instant), AbortController for race safety, sequence guard to discard stale responses.
